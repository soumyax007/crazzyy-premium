# Carzzyy Premium: website

Static single page: HTML, CSS, vanilla JS. GSAP 3.12.5 + ScrollTrigger (cdnjs), Lenis 1.1.13 (jsDelivr), versions pinned.

- Colours: `:root` variables at the top of `css/style.css` (`--bg`, `--bg2`, `--red` is the logo yellow accent, `--ink`)
- WhatsApp number (917827507408): `js/main.js` and the two wa.me links in `index.html`
- Reviews: array `R` in `js/main.js`
- Run locally: `npx serve .`
- Deploy: drag the folder into app.netlify.com/drop, or run `vercel` inside it.
